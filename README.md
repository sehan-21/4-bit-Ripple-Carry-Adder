# 4-bit-Ripple-Carry-Adder
Designed a 4-bit Ripple Carry Adder using structural modeling in Verilog on Xilinx Vivado. Implemented the design using interconnected full adders and verified functionality with a self-checking testbench. Simulated all input combinations to validate correct sum and carry propagation across stages.
Tools Used:

 ->Verilog HDL

 ->Xilinx Vivado

 Concepts Covered:

 ->Structural modeling

 ->Carry propagation

 ->Testbench design

 ->Simulation waveform analysis
